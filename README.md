## ✦ The idea

**VESPER** turns natural hand movements into digital strokes. Using a webcam and real-time hand tracking, the project aims to make a creative canvas you can control without touching a screen.

No extra hardware. Just your hand, a camera, and a little space to create.

## ✧ Planned experience

- **Air drawing** — draw by moving your index finger through the air.
- **Gesture controls** — pause, resume, pinch, and switch tools with hand gestures.
- **Canvas tools** — color palette, brush size, eraser, undo, and redo.
- **Live tracking** — mirrored camera preview and hand-landmark feedback.
- **Export** — save artwork as a PNG.
- **Accessible fallback** — mouse controls for drawing without a camera.

> This project is in development. Features listed above are planned, not yet released.
